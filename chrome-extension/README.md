# 清瀬リンク 集中モード — Chrome 拡張機能

仕事中に X / YouTube / Threads などを見ちゃう問題を物理的に潰す拡張機能。

## 機能

- 🎯 **集中モード ON/OFF トグル**
- 📑 **タブ上限**（デフォルト 4。超過した新規タブは自動で閉じる）
- 🚫 **ブロックリスト**（指定ドメインは集中モード中ブロック画面に飛ぶ。リストは popup から編集可能）
- 🍅 **内蔵ポモドーロ**（25分 → 5分休憩 を自動ループ、終わるとデスクトップ通知）
- 📊 **今日の集中合計**（ポモドーロ完了分が累積記録）

## インストール手順（淳くんがやる作業）

1. Chrome を開く
2. アドレスバーに `chrome://extensions/` と入力して開く
3. 右上の **「デベロッパー モード」** をオンにする
4. 左上の **「パッケージ化されていない拡張機能を読み込む」** を押す
5. このフォルダ（`secretary-ai-next/chrome-extension`）を選択
6. 拡張機能リストに「清瀬リンク 集中モード」が出てくる → 完了

## 使い方

1. Chrome ツールバーの清瀬リンクアイコンをクリック
2. 「🎯 集中モード」トグルを ON
3. 必要なら「タブ上限」「集中(分)」「休憩(分)」を調整
4. 「▶ 集中スタート」でポモドーロ開始
5. ブロックリスト対象サイトを開こうとすると、紫の「集中タイム中」画面に飛ぶ

## ブロックリスト初期値

```
x.com / twitter.com
youtube.com / youtu.be
instagram.com
threads.net / threads.com
tiktok.com / facebook.com / reddit.com
news.yahoo.co.jp / smartnews.com
netflix.com / amazon.co.jp/gp/video
```

popup の「🚫 ブロックリスト」テキストエリアで追加削除して「リストを保存」。

## トラブルシュート

- **タブが勝手に閉じる**: 上限を超えるとそうなる仕様。上限を上げるか集中モードを OFF
- **ブロックされない**: 集中モードが ON か確認、設定が保存されているか確認
- **ポモドーロ通知が出ない**: Windows の通知設定で「Google Chrome」を許可
- **拡張機能アイコンが見えない**: Chrome ツールバーのパズルピース🧩 から「ピン留め」

## 🌟 フローティングタイマー（v1.0.0 で追加）

ポモドーロを開始すると、**どのタブを開いていても画面右下に小さなタイマーバッジ**が出ます。

- 🟣 集中中は紫、☕ 休憩中は緑に色変わり
- ドラッグして好きな位置に移動できる（位置は記憶される）
- `_` ボタンで最小化（時刻も隠れて極小に）
- `×` ボタンで一時的に非表示（次の状態切替で再表示）
- `📺` ボタンで **Picture-in-Picture 化**：別ウィンドウで切り出して、ブラウザを最小化しても画面に浮かぶ
  - Chrome 116 以上が必要
  - VS Code や Slack で作業中も時刻が見える

タイマーが動いていない時はバッジは自動で消えます。
