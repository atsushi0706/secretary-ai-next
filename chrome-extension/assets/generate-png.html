⚠️ スクリーンショット 1280×800 (必須・最低1枚)

これは「実際に拡張機能が動いている画面」を撮る必要があります。淳くんがブラウザで実際に使って撮影してください。

  1. Chrome で拡張機能を有効にする
  2. 1280×800 にウィンドウサイズを合わせる（DevTools の Device toolbar 推奨）
  3. Print Screen or Snipping Tool で撮影
  4. 推奨ショット例:
    • サイドパネル開いた状態（秘書UI + メインタブ）
    • 集中モードON → フローティングタイマー表示中
    • popup を開いた状態（設定欄）
    • ブロック画面（紫の「集中タイム中」）
    • 時間割テキストを保存して「いま: ○○」が出ている状態
