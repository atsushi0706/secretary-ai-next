# AIラーニング：シナリオ投入からゲーム化まで

## 目的

新しい講義を「白い授業資料＋次へ」へ戻さず、シナリオデータから同じ学習アドベンチャーUIを自動構築する。

1話の基本ループは次で固定する。

1. **事件**：初心者にも一読で分かる疑問を出す
2. **掛け合い**：清瀬リンクが疑い、エリクソンが答えを教えず調査へ促す
3. **探索**：背景の3か所以上を触って証拠を集める
4. **推理**：証拠と矛盾しない解釈を選ぶ。誤答にも理由を返す
5. **誤解解除**：催眠に関するありがちな誤解を証拠で崩す
6. **自己適用**：`{{theme}}` と `{{exception}}` を使い、本人の最初の一手を選ぶ
7. **回収**：漫画の出来事、講義の原理、自分の悩みを一つの因果で結ぶ

途中の「先生に聞く」は現在地、取得済み証拠、本人の入力、直前の反応をAIへ渡す。同じ質問スレッド内の「もっと簡単に」「自分の場合は？」「別の解釈は？」は追加チケットを消費しない。

## 新しいシナリオの入れ方

`src/lib/learn/ep1-adventure.ts` と同じ形で、`defineAdventureScenario({...})` に次のデータを渡す。描画、戻る、音声スキップ、質問、証拠ファイル、誤答フィードバック、自己入力の差し込みは共通エンジンが処理する。

```ts
export const EP2_ADVENTURE = defineAdventureScenario({
  id: "ep2-case-example",
  caseNo: "CASE 02",
  title: "事件タイトル",
  question: "最初に解く疑問",
  objective: "プレイヤーが達成すること",
  background: "/learn/adventure/ep2-background.webp",
  teacherSprite: "/learn/adventure/erickson-cutout-v1.webp",
  linkSprite: "/learn/chars/link-neutral.webp",
  evidence: [/* 3件以上 */],
  nodes: [
    /* dialogue → investigate → deduction → reveal → dialogue → deduction → reveal → apply → dialogue → reveal */
  ],
});
```

利用可能なノードは以下。

- `dialogue`: 話者、表情、カメラを含む会話。`teacher` と `link` を交互に使う
- `investigate`: 背景上のタップ座標と証拠を定義する探索
- `deduction`: 正解1つと、全選択肢の即時フィードバックを持つ推理
- `apply`: `{{theme}}` / `{{exception}}` を使う自己適用。選んだ内容を `storeAs` へ保存
- `reveal`: 集めた証拠と学習原理を短く回収する発見画面

## ユーザー入力の差し込み

文章中の次のプレースホルダーは画面表示と動的音声の直前に置換される。

- `{{theme}}`: 最初に入力した「変えたいこと」
- `{{exception}}`: 1％だけ軽かった例外
- `{{resource}}`: 自己適用で選んだ使える材料

最低でも会話、問題、結末の3か所で使う。名前だけを表示するのではなく、選択肢や次の行動が実際に変わる位置へ入れる。

## 自動品質ゲート

`defineAdventureScenario` は読み込み時に `reviewAdventureScenario` を実行し、次のどれかに致命的な欠陥があればビルドを止める。

### 初心者

- 自己適用がある
- 入力したテーマと例外が後半へ戻ってくる
- 1台詞が長すぎない
- 誤答時に「なぜ違うか」がその場で分かる

### ゲーム制作者

- 探索、推理、自己適用の3操作がある
- 5台詞以上、操作なしで読み続けさせない
- 正解は一つで、全選択肢に反応がある
- 背景、証拠、カメラ、キャラクターをシナリオが指定する

### 作家・漫画家

- 清瀬リンクとエリクソンが各4台詞以上話す
- 事件、証拠、仮説、反論、解決の因果が切れない
- リビールが前の証拠を回収する

## 人間による最終チェック

自動判定を通っても、スマホ実機幅で最初から最後までプレイする。以下の質問に一つでも「いいえ」があれば公開しない。

- 初見の人が10秒以内に「何をすればよいか」を言えるか
- 30秒以内に一度は自分で画面を調べるか、考えて選ぶか
- 清瀬リンクがプレイヤーの代わりに自然な疑問を口にしているか
- 漫画の出来事が、講義の都合で唐突に利用されていないか
- 入力した悩みが、後半の台詞と選択問題にそのまま現れるか
- 質問を続けたとき、同じ説明の言い換えだけでなく本人の事例へ進むか
- 催眠を支配や万能治療として誤解させないか
