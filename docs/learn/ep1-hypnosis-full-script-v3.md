# 第1話 全文台本 v3

## 変態催眠学者の催眠の極意 — Utilization

> **今回の主役は「問題解決」でも「観察術」でもない。催眠そのもの。**  
> 足の逸話は、エリクソン催眠の考え方へ入るための事件として使う。

---

## 人がミルトン・エリクソンに期待するもの

これは実ユーザー調査の結果ではなく、第1話を作るための企画上の定義である。

人がエリクソンに会いに来る理由は、一般的な悩み整理や、最初から専門的な催眠理論を聞くためではない。

1. **催眠の天才と呼ばれたエリクソン本人から、催眠のかけ方を学びたい。**
2. **自分にも本当に催眠が起きるのか、実際に体験したい。**
3. **エリクソンが相手へ何を言い、何をして、催眠へ入れていったのかを目の前で見たい。**
4. **「私は絶対に催眠にかかりません」と身構えている相手へ、エリクソンがどう催眠をかけたのか知りたい。**
5. **本や動画で説明を聞くだけでなく、自分の答えにエリクソンが返してくれる授業を受けたい。**

ユーザーは、最初から「命令と暗示の違い」や「無反応の利用」を知りたがっているわけではない。それらは、催眠を体験した後に講義で分かる内容である。

したがって第1話は、まず「エリクソンから催眠のかけ方を学べる」と約束する。次に漫画と催眠実験を見せ、最後に「エリクソンは今、何をしたのか」へ名前をつける。

---

## 抽象的な状態を、そのまま画面へ出さないルール

「抵抗」「無反応」「変化がない」「注意が動く」といった言葉は、制作側が話を整理するための分類である。体験前のユーザーへ、そのまま見せてはいけない。

ユーザーに見せる問いには、必ず次の四つを入れる。

1. **誰が**困っているのか。
2. **何をするよう求められたのか。**
3. **実際には何ができなかったのか。**
4. **それによって、催眠をかける側が何に困るのか。**

### 不合格

> レモンを思い浮かべても、何も変わらなかった人へどうする？

何が変わる予定だったのかも、変わらないと何に困るのかも書かれていない。普通の読者には「想像しただけで何かが変わるわけがない」と見えるため、事件にならない。

### 合格

> 催眠術師から「海を思い浮かべてください」と言われた。ところが、その人は頭の中に景色を思い浮かべることができず、最初の指示から先へ進めない。エリクソンなら、この人にどう催眠をかける？

誰が、何を求められ、何ができず、催眠のどこで止まったのかが分かる。

### 不合格

> 抵抗を、どう催眠に利用する？

誰が何に抵抗しているのか分からない。ユーザーが「自分の知りたい場面」として想像できない。

### 合格

> 「私は絶対に催眠にかかりません」と言い、腕を組んで、目を閉じることも断っている相手がいる。エリクソンは、その警戒を無理に解かず、どう催眠をかける？

### 画面へ出す前の二つの検査

- **「それは普通では？」検査**：普通の反応に見えるなら、何を期待していたのかが抜けている。
- **「だから何？」検査**：その状態が催眠の進行をどう止めるのか答えられないなら、事件として成立していない。

どちらか一つでも引っかかった文は、実装へ渡さない。

---

## この回で必ず満たす約束

初めて催眠を学ぶ人が、終わった時に次の四つを自分の言葉で言える状態を作る。

1. 催眠は、強い命令で人を操ることではない。
2. 言葉やイメージへ注意を向けると、感じ方や身体に小さな変化が起きる場合がある。
3. 反応は人によって違う。起きないことも失敗ではない。
4. その人にすでに起きた反応を、次の暗示に使うことを Utilization という。

### 進行ルール

- 一画面に一つの意味だけを置く。
- 台詞は勝手に次へ進まない。ユーザーが押した時だけ進む。
- 「戻る」「音声を飛ばす」「次へ」を常に使えるようにする。
- 漫画は一ページずつ表示し、一ページ全体をスマホ画面に収める。
- 冒険パートでは自由入力を要求しない。
- 質問は講義中と終了後にできる。講義中の質問に追加チケットは使わない。

## 09｜答えに合わせて、催眠の入口を変える

**エリクソン**

**次の暗示**  
息を一度吐く間に、  
りんごの赤色が少し暗くなるところを見てください。

### 2「言葉や声が浮かんだ」

**エリクソン**  
あなたは、絵より言葉を使いやすい人ですね。  
では、頭の中の声を使います。

**次の暗示**  
頭の中で「三、二、一」と読んでください。  
一つ読むたびに、次の数字を少しゆっくり読んでみましょう。

### 3「丸さ、重さ、手触りのような感じがした」

**エリクソン**  
あなたは、頭の中の絵より、身体の感じを使いやすい人ですね。  
では、今すでに手にある感覚を使います。

**次の暗示**  
スマートフォンを持つ手の重さと、  
腕を支えている場所の感覚を確かめてください。  
力を抜こうとする必要はありません。

### 4「何をすればいいか分からなかった」

**エリクソン**  
「想像してください」という頼み方が、  
あなたには分かりにくかったのですね。  
では、想像させるのをやめます。

**次の暗示**  
この画面に実際に見えている、水色の線を一つ探してください。  
見つけた後、自分が一度まばたきするまで、  
その線を見ていてください。

## 11｜事件捜査 — 足の謎へ戻る

【画面】漫画の三場面が証拠として並ぶ。

### 証拠 A

**「動け」と強く命じた時**  
足は動かなかった。

### 証拠 B

**走っていた感覚を思い出した時**  
身体に小さな動きが起き、揺り椅子が動いた。

### 証拠 C

**その小さな動きを確かめた後**  
妹の歩き方を見て、長い練習へ使った。

**リンク**  
分かった。  
答えは「イメージなら身体を動かせる」だ！

**エリクソン**  
早すぎます。

**リンク**  
えっ。

**エリクソン**  
一つの体験だけで、  
「イメージなら麻痺が治る」とは言えません。  
そう言えば、催眠ではなく迷信になります。

**リンク**  
じゃあ、この漫画から何が言えるんです？

【推理】

**三つの証拠から、確かに言えることを一つ選ぶ。**

1. **強く命じれば、最後には誰の身体も動く**
2. **走る映像には、麻痺を治す力がある**
3. **命令した時とは違う場面で、小さな動きが起きた。エリクソンはその動きを次の練習に使った**

### 1を選んだ場合

**リンク**  
でも証拠 A では、強く命じても動いていない。

**エリクソン**  
証拠と反対ですね。  
もう一度、三つを順番に見てください。

### 2を選んだ場合

**リンク**  
そう言いたくなるけど、  
一人の体験だけで「治す力がある」とは決められないか。

**エリクソン**  
その通りです。  
催眠を学ぶ時ほど、起きたこと以上を言わないことです。

### 3を選んだ場合

**リンク**  
命令よりイメージが強い、と決めたんじゃない。  
実際に起きた小さな動きを、次へ使った。

**エリクソン**  
正解です。

## 15｜黒板 3「エリクソンの催眠」

### UTILIZATION

**その人に、今すでに起きている反応を、

# 厳格な台本審査

## 1｜「催眠から外れていないか」審査

| 区間 | 催眠との関係 | 判定 |
|---|---|---|
| サムネイル | 命令とイメージの差を催眠の謎として出す | 合格 |
| 漫画 | 命令では動かず、別の注意の向け方で身体が椅子を揺らした事件 | 合格。ただし漫画単体では催眠と断定しない |
| 漫画直後 | リンクが「リハビリでは？」と疑問を代弁し、催眠との橋を明示 | 合格 |
| 催眠の入口を探す実験 | 頭の中の絵が出ない人にも、言葉・身体感覚・実際に見えるものを使う方法があると体験 | 合格 |
| 分岐 | 実際の反応に合わせて次の暗示を変える | 合格。Utilizationを説明前に体験できる |
| 捜査 | 「イメージで治る」という誤解を否定し、起きた反応の利用へ戻す | 合格 |
| 講義 | 催眠、暗示、命令、Utilizationを順に定義 | 合格 |
| 質問 | 催眠に関する疑問へ限定し、足か実験へ戻して回答 | 合格 |
| 次回予告 | 「絶対に催眠にかからない」と身構える相手へ、どう催眠をかけるか | 合格 |

**結論：** 前版のような「困難を100と置く」「二つの場面を比べる」といった一般的な問題解決は、本編から外した。全区間が催眠の体験、誤解、原理、限界、次の謎のどれかを担当している。

## 2｜前後関係を忘れやすい人の審査

### 合格した点

- 「それ」「その条件」だけで話を進めず、身体、揺り椅子、りんご、言葉など主語を繰り返した。
- 新しい言葉は「催眠 → 命令 → 暗示 → Utilization」の順で一つずつ説明した。
- 足の漫画と催眠の間に、リンクの「リハビリの話ですよね？」を置いた。
- 黒板 4 で、足の体験と催眠を左右ではなく同じ三段で再提示した。
- 誤答では「違います」だけで終わらず、どの証拠と合わないかを示した。

### まだ注意が必要な点

- `Utilization` は英語で覚えにくい。毎回、日本語の「起きた反応を次の暗示に使う」を併記する。
- 漫画 PAGE 5 は時間が大きく進む。窓の季節変化と「長い訓練の末」を絵の中で明示する。
- 「赤いりんごを思い浮かべる」目的が消えると、また意味不明になる。必ず先に「催眠で使いやすい入口を探すため」と説明する。

## 3｜作家・エンターテインメント審査

### 興味の線

1. **不可能** — 動かない足をどう動かす？
2. **逆転** — 命令をやめ、走る自分を思い出した時に動く
3. **疑い** — それは催眠ではなくリハビリでは？
4. **実演** — 頭に絵が出ない人へも催眠をかけられるか、本人に合う入口を探す
5. **個別化** — 同じ実験でも、答えによってエリクソンの次の言葉が変わる
6. **誤答の罠** — イメージなら身体を治せる、ではない
7. **原理の回収** — 起きた反応を次の暗示に使う
8. **次の謎** — 「私は絶対に催眠にかかりません」と身構える相手へ、エリクソンはどう催眠をかける？

**机上判定：実ユーザーテストへ進める。** 説明を聞く前に、漫画と「頭に絵が出ない人へどう催眠をかけるか」で二度「どうして？」を作っている。リンクが読者の疑問と誤解を口にするため、エリクソンの独演講義になっていない。ただし、実在する読者が面白いと判定したという意味ではない。

### 弱くなる危険

- 黒板 1〜4を長く見せると、再び授業資料になる。一画面一論点、リンクとの短い掛け合い、途中質問ボタンが必要。
- エリクソンの台詞を丁寧にしすぎると個性が消える。「では、絵を無理に出させないことです」「目の前の一ミリを、次の一ミリに変える仕事です」の二本を演技の核にする。
- 「変態催眠学者」はユーザー指定の強いフックである一方、性的な意味へ誤読される可能性がある。サムネイルの絵と直後の「催眠の極意」で、常識外れの研究者という意味を即座に補強する。

## 4｜事実・安全審査

- 催眠を、注意が集まり、暗示への反応が変わりやすくなる体験として説明した。
- りんごの実験は、本人が追いやすい説明方法を探すために使い、催眠へ入ったか、催眠に向いているかの判定には使っていない。
- 「イメージで麻痺が治る」「足の動きの原因がイメージだった」と断定していない。
- ポリオからの回復には長い訓練があったことを明記した。
- ユーザーの困りごとを「催眠」と診断しない。
- 医療・心理の問題に対する催眠は、資格と訓練のある専門家の範囲だと明記した。
- 実験を断る、途中でやめる選択を残した。

## 5｜実ユーザー確認について

この文書で行ったのは、四つの観点による**机上の台本審査**であり、実在する一般ユーザー、作家、漫画家、ゲームクリエイターへのテストではない。実ユーザーが「分かった」「続きを見たい」と感じるかは、まだ証明されていない。

実装前に最低限、次の確認を行う。

1. 催眠の前提知識がない成人 5人
2. 長文や前後関係の保持が苦手な成人 5人
3. 催眠を学びたい成人 5人
4. シナリオ作家 1人
5. 漫画家または漫画編集者 1人
6. ゲームUI/UX経験者 1人
7. 催眠を臨床で扱う有資格者 1人

### 一般ユーザーへ聞く五問

1. この回は、何を学ぶ話でしたか？
2. 足の漫画と催眠が、どこでつながりましたか？
3. Utilization を自分の言葉で説明してください。
4. 分からなくなった場所はどこですか？
5. 第2話を見たいですか？ その理由は何ですか？

### 合格条件

- 15人中12人以上が「催眠を学ぶ話」と答える。
- 15人中10人以上が Utilization を「起きた反応を次に使う」に近い言葉で説明できる。

- 作家、漫画家、ゲームUI/UX経験者、有資格者のいずれかが重大な問題を出したら、修正後に同じ人へ再確認する。
