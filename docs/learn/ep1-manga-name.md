# 第1話・冒頭漫画 ネーム v2

## 形式

- 全5ページ。スマホ縦画面に1ページ全体が収まる。
- 右上から左下へ読む、日本漫画の右開き視線誘導。
- 1ページ2〜4コマ。見開き・縦スクロールは使わない。
- 横スワイプは1ページ単位でスナップする。
- セリフ・モノローグ・ナレーションは最終画像の生成時に直接入れる。HTMLで後乗せしない。
- 1919年の寝室、17歳のミルトン、母、医師、幼い妹の外見と服装を全ページで統一する。

## 物語の一本線

**歩けない身体へ命令する → 失敗する → 命令をやめた瞬間に椅子が動く → 再現できるか試す → 妹の歩行を「動きの見本」として観察する → 二年かけて歩行を取り戻す**

妹の観察を突然出さず、「身体がイメージに反応するなら、動きの見本をもっと詳しく取り込めばよい」という仮説の次に置く。

## PAGE 1｜宣告 — 「動かない身体に、意識だけが残った」

### 役割

主人公・制約・欲求を一度に提示する。読者に「この状態からどうする？」という問いを作る。

### コマ割り（3コマ）

1. **右上・横長小コマ**：1919年夏。暗い寝室の外観から、ベッドへ寄る導入。
   - ナレーション「1919年、17歳の夏。ミルトン・エリクソンはポリオに襲われた。」
2. **左上〜中央・大コマ**：ベッドのミルトン。前景で医師が母へ説明。本人は目だけで会話を聞いている。
   - 医師「動かせるのは、目と首だけです。」
3. **下・横長クローズアップ**：窓の光を映すミルトンの目。
   - モノローグ「それでも、窓のそばへ行きたい。」

### ページめくりの問い

動かない身体を、どうやって窓まで運ぶのか。

## PAGE 2｜命令 — 「意識の力では動かなかった」

### 役割

普通なら最初に試す解決策を失敗させ、後の催眠・間接暗示との対比を作る。

### コマ割り（4コマ）

1. **右上・縦コマ**：揺り椅子に座らされ、遠い窓を見ている。
2. **左上・足の接写**：毛布の下で完全に静止した脚。
   - モノローグ「動け。脚を動かせ。」
3. **右下・目とこめかみの接写**：力み、汗。斜め枠で圧迫感を出す。
   - モノローグ「動け……！」
4. **左下・大きな静止コマ**：椅子も身体も同じ位置。余白を広く取る。
   - モノローグ「……動かない。」
   - ナレーション「命令は、身体に届かなかった。」

### ページめくりの問い

命令が効かないなら、何が身体を動かすのか。

## PAGE 3｜偶然 — 「命令をやめた瞬間」

### 役割

失敗から反転する最初の驚き。物語の中心となる発見を、原因→反応→気づきの順で見せる。

### コマ割り（4コマ）

1. **右上・小コマ**：疲れて力を抜き、目を閉じる。
   - ナレーション「彼は、命令することをあきらめた。」
2. **左上〜中央・記憶の大コマ**：少年時代、外で走り回る自分の鮮明なイメージ。白く明るい縁で現実と区別。
   - モノローグ「外を走っていた、あの感じ……。」
3. **右下・極端な接写**：揺り椅子の脚が数ミリ動く。
   - 効果音「コト……」
4. **左下・目の接写**：驚いて目を開く。
   - モノローグ「今、椅子が動いた？」

### ページめくりの問い

偶然なのか。それとも、再現できる反応なのか。

## PAGE 4｜仮説 — 「動きの見本を、無意識へ渡す」

### 役割

椅子の偶然から妹の観察へ、論理の橋をかける。ここを前版の唐突さの修正点とする。

### コマ割り（4コマ）

1. **右上・中コマ**：もう一度、外で走る場面を思い描く。椅子が再び小さく揺れる。
   - 効果音「……コト」
   - モノローグ「もう一度、動いた。」
2. **左上・思考の接写**：目と椅子の脚を対角線で結ぶ。
   - モノローグ「身体は、命令よりイメージに反応する。」
3. **右下・中コマ**：幼い妹が部屋を横切る。ミルトンの視線が、妹の足へ向く。
   - モノローグ「なら、動きの見本をもっと見ればいい。」
4. **左下・横長連続コマ**：妹の「かかと→重心移動→つま先」を三つの小さな時間差で見せる。
   - ナレーション「彼は妹の歩き方を観察し、自分の中の“動きの記憶”を探した。」

### ページめくりの問い

小さな反応と観察だけで、本当に歩行を取り戻せるのか。

## PAGE 5｜回収 — 「奇跡ではなく、小さな反応の反復」

### 役割

一瞬の奇跡にせず、二年間の反復を見せる。第1話の学習原理を感情的な余韻とともに回収する。

### コマ割り（3コマ）

1. **右上・連続する小コマ群**：指先のわずかな反応、脚へ注意を向ける目、妹の足を見る目、揺れる椅子。季節の変化を窓で示す。
   - ナレーション「小さな反応を見つけては、何度も繰り返した。」
2. **左上〜中央・中コマ**：手すりにつかまり、初めて自分の脚で立つ。母と妹は奥で見守るだけ。
   - ナレーション「二年後。」
3. **下半分・大コマ**：朝の光の中、杖を使い自分の足で一歩を踏み出す。
   - ナレーション「彼は、歩きを取り戻した。」
   - 締め「動かなかった足にも、反応できる条件があった。」

## ネーム自己レビュー

- **因果**：命令失敗→イメージ→椅子の反応→再現→観察→反復→回復が切れずにつながる。
- **ページめくり**：各ページ末尾に次を見たくなる疑問か発見を置いた。
- **画面変化**：宣告の静けさ、命令の圧迫、記憶の明るさ、観察の細部、回復の開放感を順番に変える。
- **妹の必然性**：「動きの見本を取り込む」という仮説を先に置いたため、突然登場しない。
- **催眠との接続**：力で命令するのではなく、注意・イメージ・すでにある微細反応を利用する話として講義へ渡せる。
