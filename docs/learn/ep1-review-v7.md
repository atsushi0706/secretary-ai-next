## 今回見つけて直した再発原因

1. 旧ドキュメントが、Utilizationを「起きた反応を次へ使う」と短く定義していた。
2. 品質検査が「誰・本人・エリクソン・足」など特定語の有無で合否を決めていた。
3. 会話数や工程数の最低値が、意味のない台詞を足す圧力になっていた。
4. 模擬QAだけに「使える入口」という旧抽象語が残っていた。
5. 推理の直前にリンクが正解を説明していた。
6. リンクが初学者の疑問ではなく、講義内容をきれいに復唱する説明係になっていた。
7. 「目標を小さくするのと何が違う？」へのAI回答が、違いを答えず手順を繰り返していた。
8. 保存済みの途中位置を初期描画で直接読むため、本番でReactの表示不一致が起きていた。

旧台本と旧監査を正本から削除し、`singa-learning-design-foundation.md` と `ep1-canonical.md` へ置き換えた。検査は固有語を強制せず、学習者の変化と物語の因果を中心にした。
