# 第2話・実装後QA

実施日：2026-08-29

対象：第2話「『私は絶対に催眠にかかりません』と言う相手へ、どう催眠をかける？」

## 結論

第2話は、漫画から次回予告まで通し操作できる。第1話の固定文が混ざっていた講義導入と質問コンテキストは、第2話専用へ分離した。

自動品質ゲートは三重で合格した。

- 五役体験ゲート：合格、エラー0、警告0
- 学習因果ゲート：合格、エラー0、警告0
- アドベンチャー構造ゲート：合格。実演中の三つの連続会話だけ警告として残るが、これはリンクが自分で目を閉じる瞬間を切らないための意図的な演出と判断した

## 1. デザイナー審査

確認したこと：

- 390×667で全8パートの開始画面を横断
- ドキュメントの横スクロールは全画面で0
- 縦スクロールを使わず、各パートの開始画面が1画面に収まる
- 人物の画面外へのはみ出しは、立ち絵を大きく見せる意図的なクロップのみ
- 漫画は5ページすべて、1ページずつ表示
- 講義は1シーン5台詞以下、黒板と会話欄を同じ画面に表示
- 原理カードには英語名、日本語の読み方、短い原理を表示
- 詳細な意味・効能・使う時・手順は宝箱のカード詳細へ保存

修正したこと：

- 第2話の講義開始に第1話の見出しが出る固定文を廃止
- 講義開始見出しを「拒否を消さずに、なぜ催眠が始まった？」へ変更
- 第2話の質問タイムへ第1話の問題設定が渡る固定値を廃止

## 2. ゲームクリエイター審査

実装数：

- プレイヤー操作 8か所
- 自由回答 4か所
- 証拠 3個を1個ずつ順番に確認
- 推理 2回
- リンクへの催眠実演 1回
- 自分で一言を作る応用 1回

確認したこと：

- 不正解を選ぶと理由が出て、同じ場面でやり直せる
- 漫画の記憶を答える前に正解を見せない
- 証拠1/3、2/3、3/3の各段階でリンクが一問ずつ聞く
- プレイヤーの仮説を聞いてから第一推理へ進む
- プレイヤーが選んだ拒否と一言を終幕で回収する
- 自由記述は、拒否を認める言葉と観察の提案が両方あれば正解。説得や強制は不正解になる

## 3. 作家審査

一本の因果：

1. 男性が催眠を拒否する
2. エリクソンが反論せず「かからないように」と答える
3. 男性が拒否するために自分のまぶたを見張る
4. 男性自身が変化を見つけ、自分で目を閉じる
5. リンクが「目は閉じない」と拒否する
6. プレイヤーが選択を残す一言を選ぶ
7. リンクも自分で目を閉じ、プレイヤーが理由を考える
8. 講義で原理へ名前を付ける
9. リンクの次の疑問が、第3話の事件を発生させる

会話の確認：

- リンクの台詞は9本。相槌ではなく、誤解、恐れ、納得、次の疑問を担当
- 自由回答への返事は回答全文を復唱せず、核だけを短く返す
- 終幕の「まぶた」の重複を削り、「怖いまま自分で続けるか選べた」へ要約
- 「そのため」のように前文を覚えていないと解けない選択肢を、実際の発話へ変更

## 4. 演出家審査

感情の順番：

警戒 → 意外な返答 → 「なぜ？」 → 証拠を読む → 仮説 → 誤答可能な推理 → リンクで実演 → 安堵 → 原理の理解 → 次の謎

確認したこと：

- 冒頭6拍は一括表示せず、一台詞ずつ進む
- 台詞は自動送りせず、タイプライター表示後もプレイヤー操作を待つ
- 漫画の答えを先に講義で説明しない
- リンクが目を閉じる直前の三往復は、操作を挟まず緊張を切らない
- 最後は講義終了で閉じず、リンクの「頭の中のおしゃべりが止まらない」で次の謎を開く

## 5. 初学者デモ

実在の利用者調査ではなく、前後関係を保持しにくい学習者を想定したシナリオ検査として行った。

各問いで、同じ画面内に次を持たせた。

- 誰について答えるか
- どの時点について答えるか
- 何を答えるか
- 答えた後に何が分かるか

初見確認用の五問：

1. この回で学ぶことは何か
2. 男性は何を拒否しているか
3. なぜ男性はまぶたを見始めたか
4. 目を閉じると最後に決めたのは誰か
5. 「しなくていい」が罠にならない条件は何か

すべて、直前の文章を記憶していなくても漫画・問い・選択肢・講義画面だけから答えられる構成にした。
