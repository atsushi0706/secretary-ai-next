# 第2話 制作設計：「私は絶対に催眠にかかりません」と身構える相手へ、どう催眠をかける？

## 一話の問い

「催眠にかからない」と拒否した男性は、なぜ最後には自分から一つの感覚へ注意を向けたのか？

答えは「エリクソンが言い負かしたから」ではない。相手が「かかりたくない」と身構えていることをやめさせず、断る自由を残したまま、その人が自分の呼吸や身体を確かめる流れへ変えたから、とする。操作や同意の無視にはしない。

## 体験の流れ

1. 漫画で、男性が強く拒否する場面を見せる。
2. 男性は「かからないでください」と許可され、拍子抜けする。
3. エリクソンは「変わらなくてよい。そのまま、変わっていないことを確かめてください」と頼む。
4. 男性は拒否するために、自分の呼吸・まぶた・手の感覚へ自発的に注意を向ける。
5. 事件では、「相手の警戒心が消えたか」を調べない。「催眠にかかりたくない」と思ったまま、なぜ自分の呼吸や身体を確かめ始めたのかを証拠から探す。
6. 講義で初めて、相手が催眠を拒んでいる状態を、そのまま催眠の入口へ使う考え方に `抵抗のUtilization` という名前をつける。選択権、間接暗示、安全な同意もここで説明する。

## 冒頭漫画・5ページのネーム

各ページはスマホ一画面。1ページを1枚の完成漫画として生成し、コマ・吹き出し・台詞まで画像内に確定する。

### 1ページ：対立を置く

- 右上の大コマ：診察室へ入る男性。腕を組み、椅子には座らない。
- 男性「先に言います。私は催眠なんか絶対にかかりません」
- 左下の小コマ：リンクが身構える。
- リンク（心の声）「始まる前から、完全拒否だ」

### 2ページ：予想を外す

- 上段：エリクソンは説得せず、穏やかに見上げる。
- エリクソン「分かりました。では、かからないでください」
- 下段の横長コマ：男性の腕がわずかに緩む。
- 男性「……え？」

### 3ページ：「かかりたくない」をやめさせずに、身体へ注意を向けてもらう

- 右コマ：エリクソンが空いた椅子を示す。命令する手つきにはしない。
- エリクソン「変わらないままで結構です。そのまま、何も変わっていないことを確かめてください」
- 左コマ：男性は警戒したまま、自分の身体へ注意を向ける。
- 男性（心の声）「変わっていないことを、確かめる……？」

### 4ページ：最初の反応

- 上段3コマ：呼吸、まばたき、指先の順にクローズアップ。
- ナレーション「拒否するために観察した。その観察が、注意の向きを変えた」
- 下段：男性が自分から椅子に座る。
- 男性「呼吸だけは、さっきよりゆっくりかもしれない」

### 5ページ：事件の問い

- 大コマ：男性は腕を組んだままだが、エリクソンの声を聞いている。「催眠にかかりたくない」という警戒が消えた表現にはしない。
- リンク「拒否は、なくなっていない。それなのに、対話は始まっている」
- タイトル「『絶対にかからない』と言ったのに、なぜ自分の呼吸を確かめた？」
- 問い「男性は、なぜエリクソンを警戒したまま、自分の呼吸や指先を確かめ始めたのか？」

## アドベンチャー

- 事件名：`「絶対にかからない」と言った男が、自分の呼吸を確かめた`
- 証拠1：エリクソンは説得も命令もしなかった
- 証拠2：「かからない」という選択を認めた
- 証拠3：男性自身が「変化していないか」を観察した
- 第一推理：男性が自分の呼吸を確かめ始めたのは、エリクソンが「催眠にかかりたくない」という気持ちをやめさせず、「何も変わっていないことを自分で確かめてください」と頼んだから。
- 第二推理：観察を続けられた理由は、本人の選択権が残っていたこと
- 自己適用：自分が「やりたくない」と感じる課題について、拒否を消さずに自分で選べる最小行動を一つ選ぶ

## 講義

1. 抵抗は邪魔ではなく、本人を守る反応でもある。
2. 抵抗を利用するとは、従わせることではなく、選択権を保ったまま反応を材料にすること。
3. 「しなくてよい」は逆心理の罠ではない。断る自由が本当に残っている必要がある。
4. 自発的な注意・観察・小さな反応を見つけ、本人の同意の範囲で広げる。
5. 同意を無視した誘導、治療効果の断定、医療行為の代替は行わない。

## 絵の固定ルール

1. ネームを文章とラフで承認する。
2. 男性・エリクソン・リンク・診察室の設定画を先に固定する。
3. 5ページを同じ設定画からまとめて制作する。
4. 台詞は生成画像の中へ入れ、後付けHTML吹き出しにしない。
5. 承認済み画像をマニフェストで固定し、文章修正のたびに差し替えない。
6. 棒人間や仮画像を本番UIへ出さない。未完成時は同じ背景・立ち絵の「次回事件予告」を表示する。
