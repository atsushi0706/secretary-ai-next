# 第3〜5話｜5視点レビューと操作試験

この記録は、実在の人へのユーザーテストではなく、制作前提に固定した5つの視点によるシミュレーションレビューと、390×667px のブラウザ操作試験の結果である。

## 1. デザイナー視点

- 第3〜5話の冒頭、5ページ漫画、推理、教室、原理カード、次回予告で横はみ出し 0px。
- 漫画は縦長1ページを1画面に収め、ボタンまたは横スワイプで1ページずつ表示する。
- 新キャラクター「雨宮ミオ」は、通常・不安・決意の3表情を同一衣装・同一人物として統一した。
- エリクソン、リンク、ミオの三人表示をスマホ幅で確認し、台詞・人物・主操作が同じ画面内で判別できる。
- QA画像: `artifacts/qa/ep3-briefing-mobile.png`、`artifacts/qa/ep3-adventure-cast-mobile.png`、`artifacts/qa/ep5-breach-briefing-mobile.png`

## 2. ゲームクリエイター視点

- 各話で、プレイヤーが記憶を話す → 本を3段階で確認する → 各段階でリンクへ答える → 仮説を話す → 推理する → 相手へ自分の一言を作る、の順に操作する。
- 第4・5話では全3問で不正解を実際に選び、理由のフィードバック後に選び直して進めることを確認した。
- 選択肢だけでなく自由記述も送信でき、回答が次の会話と最後の振り返りへ戻る。
- 第5話では原理カードの保存データを削除せず、物語上の保管庫だけを封印する。喪失の緊張とデータ安全性を両立した。
- 第3話で仲間が増え、第4話で三人の成功体験と鍵の伏線を置き、第5話でミオ不在・カード消失・本人の告白へ反転する。

## 3. 作家視点

- 各話の最初に「今回、催眠で何を解くか」を日常の困りごとで提示した。
- 漫画後は、エリクソンまたはリンクが漫画の出来事を言い直してからプレイヤーの場面へ橋渡しする。
- 「反応」「入り口」「最初」だけで意味を省略せず、誰が・どの時点で・何をしたかを質問文に含めた。
- リンクは単なる復唱役にせず、初学者の疑問、プレイヤーへの質問、誤解、納得、次回への未解決問題を担う。
- ビルド時のシナリオ品質ゲートで見つかった、回答後の会話不足、リンクの発話不足、最終場面の問い不足を修正した。

## 4. 演出家視点

- 冒頭は全文を一度に出さず、エリクソン → リンク → エリクソンの短い掛け合いをタップごとに見せる。
- 第3話は「止められない苦しさ」から「仲間になる安堵」、第4話は「人前で固まる緊張」から「三人で成功する信頼」、第5話は「喪失と裏切り」から「生徒ではなく調査役になる決意」へ感情を動かす。
- 第4話の最後にミオが保管庫の片づけを手伝い、鍵の場所を知る。第5話の裏切りが後付けに見えないようにした。
- 第5話では、裏切りをすぐ悪意と断定しない。次の話を見たくなる謎と、催眠学習の「混乱から現在へ戻る」を同じ事件で成立させた。

## 5. 完全初学者視点

- 各話の問いは一画面につき一つ。正解を聞く前に、漫画の具体的な場面を見直せる。
- 専門用語は、英語名・読み方・短い意味・効能・使う時・3段階の使い方を原理カードへまとめた。
- 第3話: 考えを消す授業ではなく、考えが浮かんだ後を変える授業。
- 第4話: 「落ち着いて」ではなく、今分かる事実を二つ確かめ、次の一つを提案する授業。
- 第5話: 犯人を当てる授業ではなく、事実・未確定・次の確認を分け、混乱していても選択を取り戻す授業。
- 講義中と講義後の質問には、その話で選んだ場面・実践した一言・学習目的をコンテキストとして渡す。
