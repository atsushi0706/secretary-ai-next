# ミルトン・エリクソン編 第1〜10話 実装シナリオ総合監査

作成日: 2026-08-31

## 結論

ユーザーの認識どおり、**第3話以降は「文章を少し直せば完成する」状態ではない**。

ただし、すべてが同じ程度に壊れているわけではない。第3・5・7・9・10話には残せる学習着眼点がある。一方で、現在の漫画・会話・証拠・講義を一つの出来事として読むと、第4・6・8・9・10話には、人物、事実、発話、因果のいずれかを復元できない重大な破綻がある。特に第6話と第8話は、**教材が示す証拠そのものが、教材の結論と反対**になっている。

現状を端的に言うと、次の状態である。

> 学習原理ごとの部品は並んでいる。しかし、人物が体験した一つの出来事としてはつながっていない。

このため、第3話以降を話数ごとに部分修正する前に、シリーズ全体の正史となる事件台本を作り直す必要がある。

## 監査対象と方法

今回、次の三層を別々に読んだ後、同じ出来事として突き合わせた。

1. 第1〜10話の実装データ
   - 導入
   - 漫画参照
   - 橋渡し
   - 自由記述
   - 選択肢と正誤フィードバック
   - リンクとの調査会話
   - 証拠確認
   - 講義、スライド、原理カード
   - 終了会話と次話予告
2. 漫画全50ページ
   - コマ割り
   - 映っている人物
   - 表情、衣装、位置関係
   - 台詞と心の声
   - 実際に描かれた行動
3. 現在の品質チェックコードと既存QA記録
   - 何を検査しているか
   - 何を検査していないか

実装テキストの全量は[実装文字起こし](./erickson-implementation-transcript.md)、漫画50ページの目視結果は[漫画目視文字起こし](./erickson-manga-visual-audit.md)に分離してある。本書は、その二つを統合した判定である。

## 「破綻」の判定基準

興味を引くために答えを隠すことと、意味が分からないことは別である。

### 破綻していない状態

- 誰の問題なのかが分かる。
- その人が何を望み、何に困っているかが分かる。
- 漫画で起きた事実と、その後の質問・証拠・講義が一致する。
- 人物がその情報を知っている理由がある。
- 行動の前に動機があり、結果との因果を追える。
- 学習者が答えを考える余白はあるが、問いの主語・目的・前提は欠けていない。
- 学んだ原理が、その人物の望む方向へどう役立ったかを具体的に確認できる。

### 破綻している状態

- 同じ人物の外見や役割が途中で変わる。
- 漫画、本文、証拠、講義が別の出来事を語る。
- 心の声を、聞いていない人物が知っている。
- 発話していない台詞を、後の講義が発話済みとして扱う。
- 示された証拠から、教材の結論を導けない。
- 原理を出題するためだけに扉、装置、事件が出現する。
- キャラクターの欲求ではなく、教材の正解に合わせて人物が動く。

## 各話の詳細

### 第1話 — 概ね成立

#### 成立している点

- 1919年、17歳のエリクソン、ポリオ、動かない身体、窓辺へ行きたいという望みが一ページで分かる。
- 「動け」と命令しても動かないところから、走っていた感覚、揺り椅子、妹の歩き方へ注意が移る。
- 二年間の観察と反復が描かれ、一回の暗示で治った奇跡話にはしていない。
- 漫画の出来事をリンクと一緒に三段階で確かめる構成は、シリーズ内で最も学習と物語がつながっている。

#### 注意点

- 漫画では最初に動いたのは「足」ではなく「揺り椅子」と読める。後続文で「足が初めて動いた」と混同しないこと。
- 「身体は命令よりイメージに反応する」は医学的事実として一般化しすぎないこと。

### 第2話 — 成立

#### 成立している点

- 「絶対にかからない」と拒否する男性に、エリクソンが拒否をやめさせず、その拒否を観察行動へ変える。
- 男性は、自分のまぶたと呼吸を自分で確かめ、最後に自分から目を閉じる許可を求める。
- エリクソンの最後の言葉も「それは、あなたが決めてください」であり、出来事と講義の主題が一致する。
- 誰が、何を望み、何を拒否し、どう変化したかを目で追える。

#### 注意点

- 後続話が第2話の「拒否をそのまま利用する」構造を、単なる言い換えテンプレートとして模倣している。第2話が成立するのは、男性の実際の反応を観察しながら次の言葉を作っているからである。

### 第3話 — 学習操作は残せるが、人物と物語が不成立

#### 残せる点

- 「考えを消す」のではなく、「考えが浮かんだ瞬間を呼吸を確かめる合図として使う」という操作は理解できる。
- ミオの変化も「考えが消えた」ではなく「追いかけなくてよくなった」とされている。

#### 破綻

- 1ページ目で「考えを止めればいい」と言う男性と、2ページ目で「止めなくてよい」と言う指導者が、同じ顔・髪・服に見える。
- 同一人物なら発言が突然反転し、別人なら描き分けられていない。
- 指導者の名前も役割もない。エリクソンなのか、リンクなのか、淳なのか、別の教師なのか判断できない。
- 最終ページに、それまで場面にいなかった別の若い男性が加わる。
- ミオが何を始めたい人で、この苦しさを解くと何をできるようになりたいのかがない。技法の実演だけで、人間の物語がない。
- 内容は呼吸への注意移動であり、なぜこの場面を「エリクソン催眠」として学ぶのかが十分に立っていない。

### 第4話 — 当事者が画面上で入れ替わる

#### 残せる点

- 「落ち着いて」「いつも通り」という抽象的な励ましではなく、「足が床についている」「息を吐けている」「次の一言」という確かめられる事実から進む着眼点は使える。

#### 破綻

- 漫画のナレーションは「リンクは前へ出た」と始まり、壇上には成人男性が立つ。
- 3ページ目の最後で、「こんばんは」と話す当事者がミオへ入れ替わる。
- 4ページ目もミオがそのまま発表を続ける。
- 実装導入はリンクの失敗、講義タイトルはミオの失敗、漫画は途中でリンクからミオへ交代する。誰の問題を解いた話か定まっていない。
- 「二つの事実＋一つの提案」という形が、その人の反応を観察して言葉を変える行為ではなく、正解の公式になっている。

### 第5話 — フックはあるが、人間の裏切りではなく教材用の事件

#### 残せる点

- 原理カードが消え、鍵とメモだけが残り、ミオの映像が流れる導入は、続きを見たくなる事件になっている。
- 「分かっている事実」と「まだ決められない意味」を分ける入口も機能する。

#### 破綻

- ミオがカードを持ち出す個人的な理由、失うもの、怖れ、二人との関係が描かれない。
- 目に鍵を映す演出は、後で善意に反転したい人物を先に悪人として強く記号化している。
- 誰がプロジェクター映像を起動したのか、なぜミオがその方法を選んだのかがない。
- 黒髪の成人男性がリンクなのか教師なのか判別できない。
- 本実装が「混乱後に事実・不明点・次の行動を分けること」を Confusion Technique と呼んでいる点は不正確である。エリクソンの混乱技法は、語呂、無関係な挿入、非連続な言葉などで通常の意味づけを過負荷にし、トランスへ導く技法として説明されている。事件後の整理術そのものではない。[Milton H. Erickson Foundation](https://catalog.erickson-foundation.org/page/ericksonian-hypnosis-therapy-techniques)、[原著論文情報](https://pubmed.ncbi.nlm.nih.gov/14114336/)

### 第6話 — 証拠が結論を否定している

#### 残せる点

- 「いい点を取れ」「我慢しろ」「迷惑をかけるな」という声によって、自分の望みを言えなくなった主人公の過去は、催眠学校へ入る理由として重要である。
- 文化的催眠を主人公の生活史から描こうとした方向は正しい。

#### 致命的破綻

- PC画面には明確に「**一人で来れば、カードの場所を教える**」と書かれている。
- その直後、別の人物が「**一人で来い、とは書いてない**」と言う。
- 講義は「リンクが『一人で行く』という意味を足し、命令へ変えた」と結論づける。
- しかし原文は、一人で来ることを情報開示の条件として明示している。命令文ではないが、「一人」という意味をリンクがゼロから足したわけでもない。
- 条件、含意、前提、聞き手の推論が一つに混ざっている。
- 授業例の「『あなたはすぐ変われる力がある』を『私は嬉しくない』と否定しても、『変われる力がある』は残る」も、そもそも元の命題を否定していないため、説明になっていない。
- 漫画5ページ目は第7話の扉問題であり、第6話の結末が別話の導入に置き換わっている。

この回は表現修正では救えない。教えたい言語現象を先に一つへ定め、その現象が本当に起きる文章から作り直す必要がある。

### 第7話 — 論理問題としては成立するが、ドラマと催眠がない

#### 残せる点

- 「今、一人で入る」「一分後、一人で入る」の違いと共通点は明確である。
- 二択の共通前提を見抜き、どちらも選ばず、別の道を探す考え方は理解できる。

#### 破綻・不足

- 2ページ目の集合図で答えを説明しており、読者が考える前に考察が終わる。
- 廊下をメジャーで測ると別通路が見つかる因果がない。
- 扉、配線盤、管理通路、資料室が、原理問題を解いた報酬として都合よく現れる。
- リンクと淳の感情、関係、失敗、選択の代償がない。人物ではなく問題を解く駒になっている。
- Therapeutic Double Bind は「二択に含まれる前提を見抜くパズル」と同義ではない。元来は、治療的変化につながるよう複数の選択肢を構成する臨床上の概念であり、現在の実装は論理パズルへ単純化しすぎている。[Erickson & Rossi, 1975](https://pubmed.ncbi.nlm.nih.gov/1146705/)

### 第8話 — 漫画と教材が別の物語

#### 残せる点

- 直接説明が届かない時、物語を通して別の見方を試すという方向は使える。
- 「盗んだ鳥」と思わせた後、「守った鳥」と読み替える構造自体には転換がある。

#### 致命的破綻

- 漫画では、雷で塔が崩れ、鍵は鳥の巣に残って助かる。
- 実装の証拠説明では、火が保管庫を包み、鍵は森の外の箱にある。
- 原因、場所、保存方法がすべて異なり、同じ物語ではない。
- 漫画は鳥とミオの対応を直接描き、リンクも「ミオも盗んだと決めつけられた」と答えを言う。本人に意味を発見させる講義と反対に、作者が正解を固定している。
- 第3〜5話のミオはボブヘアの成人女性風だが、第8話から長髪・リボン・制服の少女になる。
- 「ミオが戻ると二人の学びを壊す」という重大な葛藤に、原因も約束もない。

### 第9話 — 心の声を会話した事実へ変えている

#### 残せる点

- 「戻らなくてもよい」「一歩だけ試してもよい」「ここにいてもよい」と選択権を残す言葉の方向はよい。
- 相手の目的への同意と、具体的な方法への同意を分ける第10話への入口にもできる。

#### 破綻

- 漫画でミオの「戻りたい」「戻れば壊す」は内心であり、口にしていない。
- リンクも「今すぐ戻れ、と言いそうになった」と考えただけで、実際には言っていない。
- それなのに後続本文では、ミオが二つの気持ちを話し、リンクが「戻れ」と言った瞬間に身体が固まったことになる。
- 二人がノートへミオの内心を正確に書き出し、心を読んだように進む。
- 催眠導入、観察、反応の積み重ねがなく、一つの許可文を言うと予定どおり一歩進む。
- 「出口まで三歩」も床に三枚の印を置いた教材上の都合で成立している。

### 第10話 — 教えている倫理を、物語そのものが破っている

#### 残せる点

- 「カードを返したい」という目的への同意と、「命令される」という方法への同意は別、という整理は明確である。
- 途中で同意を撤回できること、本人が方法を選ぶことも、シリーズの倫理基準として残せる。
- 臨床催眠を訓練された医療専門職が倫理的・科学的に用いるべきだという一般原則とも方向は合う。[American Society of Clinical Hypnosis](https://asch.net/about-asch/)

#### 破綻

- 「ミオへ『戻れ』と暗示すれば開く」装置が、世界のルールや設置者の動機なしに現れる。
- 「暗示実行」を押しかける人物と止める人物が、同じ顔で区別できない。
- 手動の三人用解除板がすぐ見つかり、倫理的葛藤が都合よく消える。
- 指定された装置を三人で操作した後に「誰も従わなかった」と断言するため、表現と行動が一致しない。
- 漫画は一枚のカードだけが戻るが、本文は全カードが戻ったとする。
- エリクソンは事件中に不在で、最後だけ現れて淳を認定する。
- 最大の矛盾は、ミオまたは学校側が、カードを無断で消し、映像と暗号で二人を誘導し、ミオへの命令を要求する装置まで用意したことである。最終話は「相手を操らず選択を守る」と教えるが、物語全体は二人の同意なしに喪失、誘導、試験を仕掛けている。
- 誰が計画し、ミオは何に同意し、二人へなぜ説明せず、何を償うのかが最後までない。

## 視覚面のシリーズ破綻

### 1. キャラクターの同一性を維持できていない

- UIのエリクソンは白髪の成人男性、リンクは小柄な少年風である。
- 第3話の指導者は黒髪の若い成人男性で、誰か分からない。
- 第4〜5話の「リンクらしき人物」は黒髪の成人男性で、UIのリンクと一致しない。
- 第6〜10話のリンクと淳は、顔、髪、服がほぼ同じである。
- ミオは第3〜5話のボブヘア成人女性風から、第8〜10話の長髪制服少女へ変わる。

これは画風の好みではなく、シナリオ理解に直接影響する。名前のないコマで話者を特定できないため、発話、判断、成長を人物へ帰属できない。

### 2. UI立ち絵と漫画に共通の世界がない

本編UIはカラーのゲーム立ち絵、漫画は写実寄りのモノクロであること自体は成立し得る。しかし、年齢、頭身、衣装、髪型、顔の特徴が共有されていないため、「同じ人物を別媒体で描いた」と認識できない。

### 3. コマが事件ではなく説明図になっている

- 第7話の集合図
- 第8話の鳥＝ミオの直接対応
- 第9話の三歩を示す床
- 第10話の暗示実行装置と三人用解除板

これらは人物が世界の中で発見した事実ではなく、学習の正解を表示する教材部品に見える。漫画を読む体験が、講義資料を見る体験へ変わっている。

## 学習内容としての根本問題

### 1. 「催眠」が一般的なコーチング技法の総称になっている

第3話以降では、呼吸への注意、事実整理、言語の論理、二択の再検討、比喩、許可、同意などを、ほぼすべて「エリクソン催眠の原理」と呼んでいる。

これらは支援に役立つ考え方になり得るが、何でも催眠と呼ぶと、初学者は「催眠とは何か」を学べない。エリクソニアンな Utilization の核は、クライアントがすでに持つ状況、習慣、信念、症状、抵抗などを、その人自身の目標へ役立てることであり、個別性と主体性が重要である。[Milton H. Erickson Foundation](https://www.erickson-foundation.org/blog/utilization)

現在は、その人の反応から次の言葉を作るのではなく、各話のカード名へ出来事を当てはめている。

### 2. 技法名が先にあり、出来事が後から作られている

- 第5話は事件後の整理を Confusion Technique と呼ぶ。
- 第6話は条件、含意、前提、推論を Verbal Implication にまとめる。
- 第7話は二択パズルを Therapeutic Double Bind とする。
- 第10話は一般的な同意原則を Erickson Principle 08 とする。

原理名を一話ずつ獲得させるゲーム設計が先にあるため、歴史的・臨床的な概念がストーリー用の短い公式へ縮み、名称と体験がずれている。

### 3. 効果を予定調和で出している

第3話では呼吸、第4話では次の一言、第9話では一歩、第10話では同時操作が、ほぼ一回の正解文で成功する。選択肢も正解が露出している。

間違いがなぜ相手に届かなかったかを観察し、言葉を変え、相手の反応から再び学ぶ過程がない。したがって、読者は「催眠を学んだ」のではなく「正解選択肢を見分けた」状態になる。

### 4. 文化的催眠がラベルになっている

第6話の「いい点を取れ」「我慢しろ」「迷惑をかけるな」は、主人公が社会の常識を自分の声として取り込んだ具体例になり得る。

しかし他話では、登場人物のあらゆる悩みに「文化的催眠」という名前を後付けしている。誰から、いつ、どの場面で、どんな利益や罰と結びついてその常識を覚えたのかがないため、「社会の常識が本当の自分を縛る」というシリーズの中心テーマになっていない。

### 5. 望む未来がない

第1話には「窓辺へ行きたい」「再び歩きたい」、第2話には「自分の意思を守ったまま体験したい」がある。

第3話以降は、問題を解くと何を実現したいのかが薄い。読者が「私もこの技術で誰かを支援したい」「自分もそこへ行きたい」と感じる具体的な変化がなく、カードを回収して次話へ進むことが目的になっている。

## なぜ既存チェックで見抜けなかったか

現行チェックは、シナリオの真偽ではなく、データ構造の充足を検査している。

### コード上の限界

- `episode-review.ts` は、自然な文章と漫画の連続性を別の手動監査対象としている。
- 因果は `causalChain` の要素数と空文字の有無を確認するだけで、その因果が漫画のコマに本当に存在するかを見ない。
- 漫画はフレーム数が2枚以上かを確認するだけで、画像内の人物・台詞・出来事を見ない。
- 文化的催眠の根拠は、情報源URLが存在するかを確認するだけで、その根拠が話中の悩みと対応するかを見ない。
- 問いは内部フィールドが埋まっているかを確認するだけで、画面に出る一文の主語、前提、目的を読まない。
- 5役チェックは、ビート数、選択肢、自由記述、推論、リンクの台詞、講義シーン数などを数える。内容の矛盾は判定しない。

### 既存QA記録の限界

- 「デザイナー、ゲームクリエイター、作家、演出家、初学者」は実際の別人による試遊ではなく、同じ実装データに対する模擬レビューである。
- 第3〜5話の記録は、ミオの外見が一貫していると評価しているが、第8話以降では別人化している。
- 第6〜10話の記録は因果を画像で確認したとしているが、第6話と第8話の正面矛盾を見落としている。

つまり、チェック表の全項目が `PASS` でも、**漫画の証拠と本文の結論が反対**という事態が起こる。

## 根本原因

### 1. データモデルが物語を作っている

ほぼ全話が、次の同じ順序で作られている。

> 問い → 漫画 → 自分の場合 → 漫画の再確認 → 三つの証拠 → 仮説 → 三択 → 応用 → 期待どおりの変化 → 講義 → 倫理問題 → 原理カード → 次話予告

この器へ毎回別の原理を流し込んだため、人物が自然に次の行動を取るのではなく、次のUIブロックを出すために行動している。

### 2. 正史が三つに分かれている

現在の一話には、少なくとも三つの独立した正史がある。

1. 漫画画像に描かれた出来事
2. 実装本文と証拠説明が語る出来事
3. `foundation` や `causalChain` が定義する学習上の出来事

三つを同じ場面ID、人物、発話、事実へ結びつける台帳がないため、別々に生成・修正され、食い違った。

### 3. 人物ではなく原理カードが主人公になっている

ミオ、リンク、淳が「何を怖れ、何を守り、何を望むか」より、次にどの原理カードを獲得するかが優先されている。そのため裏切り、葛藤、和解、成長が、教材を出す装置になる。

### 4. QAが自己申告を再確認している

実装データに「因果がある」「初学者に分かる」「漫画と一致する」と書かれていれば、その同じデータを元に合格させている。証拠である画像や、画面上の自然な一文を独立に検証していない。

## 残すべきもの

全面破棄ではなく、次の核は残せる。

- 第1話: 命令から感覚・記憶・観察へ注意を移し、長く練習する流れ。
- 第2話: 拒否を奪わず、本人の観察と選択へ変える流れ。
- 第3話: 消そうとした思考を、呼吸を確かめる合図として使う操作。
- 第4話: 抽象的な励ましより、今確認できる事実から次の一動作を作る着眼点。
- 第5話: 喪失事件のフックと、事実と解釈をいったん分ける姿勢。
- 第7話: 提示された二択の共通前提を検討する論理。
- 第8話: 直接説明ではなく、物語を使って別の見方を試す発想。
- 第9話: 相手が動かないことを失敗扱いせず、選択肢を残す姿勢。
- 第10話: 目的への同意と方法への同意を分け、途中で撤回できる倫理。

これらは「完成した話」ではなく、次の正史を作るための素材である。

## 改修の優先順位

### P0 — 第3〜10話の部分修正を止める

現在の矛盾は言い回しではなく、事件、人物、証拠、原理の関係にある。画面文言だけを直すと、漫画との距離がさらに広がる。

### P1 — 一つの正史台帳を作る

各コマ・各会話に、最低限次の項目を持たせる。

| 項目 | 内容 |
|---|---|
| 場面ID | 話数・ページ・コマ |
| 時間と場所 | いつ、どこで |
| 登場人物 | その場に誰がいるか |
| 観察できる事実 | 絵と台詞から誰でも確認できること |
| 発話 | 実際に声に出した言葉 |
| 内心 | 本人しか知らない言葉 |
| 情報の所有者 | 誰が何を知っているか |
| 欲求 | その人が実現したいこと |
| 障害 | 何が止めているか |
| 選択 | 本人が何を選ぶか |
| 結果 | その選択で何が具体的に変わるか |
| 学習証拠 | 原理を導く実際の出来事 |
| 後続参照 | 後の質問・講義がどの事実を参照するか |

漫画、本文、質問、講義は、この台帳以外から事実を作らない。

### P2 — キャラクターバイブルを作る

- 正面、横顔、全身
- 年齢、身長差、髪型、衣装、象徴物
- 表情差分
- 一人称、語尾、語彙、発話の長さ
- 他人物との関係
- 各話で知っていること
- 変化してよい部分と変えてはいけない部分

リンクと淳は、シルエットだけでも見分けられる必要がある。ミオの年齢と外見は第3話から第10話まで固定する。

### P3 — 5〜10話をミオの欲求から組み直す

「裏切らせる」から始めず、次を先に決める。

- ミオは何を救いたいのか。
- なぜ正面から頼めないのか。
- 文化的催眠によって、どんな選択をできなくなっているのか。
- カードを持ち出す以外に何を試し、なぜ失敗したのか。
- リンクと淳に何を期待し、何を恐れているのか。
- 二人は何を失い、なぜなお関わるのか。
- ミオは最後にどの責任を引き受けるのか。

ここが決まれば、第5話の裏切り、第6〜9話の探索、第10話の倫理は一つの因果へつながる。

### P4 — 原理ごとに実在する相談場面を置く

読者が「その気持ちは分かる」「この技術で支援してみたい」と感じるには、抽象的な教材問題ではなく、次が必要である。

- どんな人が
- どんな場面で
- どんな言葉に縛られ
- 本当は何を望み
- 支援によって最初の何を選べたか
- その後、生活のどこが少し変わったか

毎話同じ形式の後日報告にする必要はない。再会、第三者の変化、失敗後の再挑戦、選ばなかった行動、噂、手紙など、物語上自然な形で結果を見せる。

### P5 — QAを「存在確認」から「反証」へ変える

各話で機械・人間の両方が次を確認する。

1. 漫画の各発話者とキャラクターIDが一致するか。
2. 心の声を他人が知っていないか。
3. 後続文が参照する事実は、前の漫画か会話に実在するか。
4. 証拠の文章は、画像の内容と一致するか。
5. 正解の反対を支持する証拠がないか。
6. 原理名を外しても、人物の行動理由が成立するか。
7. 選択肢を外しても、次の行動が人物の欲求から自然に出るか。
8. 初学者が「これはどういう意味？」ではなく、「この先どうなる？」と質問するか。
9. 誤答後に正解を読むだけでなく、何を見落としたかを自分の言葉で説明できるか。
10. 実機で全選択肢、戻る、自由記述、音声入力、次画面遷移を操作したか。

## 推奨する再制作順

1. 第1・2話を、完成基準の参照話として固定する。
2. 主人公が催眠学校へ来た理由と、作りたい世界を第3話までに物語化する。
3. リンク、淳、ミオの人物設定と、5〜10話を貫く一つの事件台本を作る。
4. 各話に「相談者の望む具体的な未来」と「観察できる小さな変化」を置く。
5. その出来事に本当に合う催眠原理だけを選ぶ。合わなければ原理名か話を変える。
6. 正史台帳から漫画ネーム、会話、証拠、講義を同時に作る。
7. 漫画を人間が目視し、文字起こしへ戻して、再び正史台帳と照合する。
8. 最後にUI操作と全分岐を実機で通す。

## 最終判定

第1・2話は、出来事と学習が同じ方向を向いているため、シリーズの基準として使える。

第3話以降は、よいアイデアや原理の断片はあるが、現在のまま「完成したシナリオ」とは判定できない。中でも第6・8話は証拠と結論が矛盾し、第4・9話は当事者または発話事実が入れ替わり、第10話は教えている倫理を物語自身が破っている。

したがって次に必要なのは、文章の磨き込みではない。

> 誰が、何を望み、何を実際に見聞きし、なぜ次の行動を選んだかを一つの正史に戻すこと。

その正史ができてから、漫画、対話、選択、講義、原理カードを作り直すのが最短である。
