# EP1 実装文字起こし
タイトル: 『やらなきゃ』と思うほど動けない時、催眠をどう使う？
副題: 変態催眠学者の催眠の極意01｜Utilization
一覧フック: 『やらなきゃ』と思うほど、動けない。
学習前: 『やらなきゃ』と自分へ命令する / できない結果を見て、また自分を責める / 同じ命令をもっと強くする
学習後: できない方向からいったん目を外す / 今分かる感覚・できる動作へ注意を移す / その方向から最初の一動作を暗示する
持ち帰り: 『できないのに、やらなきゃ』という自己暗示から目を外し、今できる方向から次の暗示を作る。

原理: 今確かめられる事実を二つ。 / その続きへ、選べる暗示を一つ。

カード後(teacher): 二つと一つは暗記の呪文ではありません。相手の返事が違えば止まり、別の事実へ戻ってください。

台詞(teacher): 情報を覚えるなら説明が役立ちます。状態や見方を変える時は、本人が経験する気づきが必要なことがあります。
台詞(teacher): 『反論したら面倒な人と思われる』という文化的催眠がある時、正しい説明を重ねても本人の言葉は出てきません。
台詞(teacher): 催眠は情報を押し込むのではなく、別の体験を呼び起こすためにも使われます。

[講義2] Metaphor は、似た構造を渡す
台詞(teacher): 鳥とミオは同じ人物ではありません。『持ち出した行動が、後の場面で別の意味に見える』構造が似ています。
