# ミルトン・エリクソン編 第1〜10話 文・画面単位監査

作成日: 2026-08-31

## この監査の読み方

前回の総合監査は代表的な破綻だけを取り出しており、全件監査として不足していた。本書では、実装全文のラベルと画面IDを基準に、表示文、問い、選択肢、フィードバック、漫画参照、講義、カード、終幕を画面単位で判定する。

- **成立**: 主語、前提、因果、前後の事実が一致し、そのまま残せる。
- **要修正**: 意図は成立するが、断定、重複、不自然な日本語、誘導、説明不足がある。
- **破綻**: 漫画または前後の事実と矛盾する、人物を特定できない、問いに答えられない、結論を証拠から導けない。
- **設計問題**: 一文の修正ではなく、体験順、役割、分岐、学習原理との接続を変える必要がある。

判定対象の原文は[実装全文](./erickson-implementation-transcript.md)、絵そのものの記録は[漫画全50ページ目視記録](./erickson-manga-visual-audit.md)を参照する。

## 選択肢と分岐
