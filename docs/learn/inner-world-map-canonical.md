# インナーワールドマップ教材：制作前提と正典

## この教材で何をするか

これは、受講者へいきなり自己分析やセッションをさせる教材ではない。清瀬淳と清瀬リンクの掛け合いを通して、顕在意識、潜在意識、文化的催眠、深層自己、統合を順番に理解する学習教材である。

各章は、短い掛け合い→日常の具体例→図解→選択式の理解確認→自分の一場面への短い当てはめ、の順で進む。自分の地図を作るのは、言葉の意味と使う理由を理解した後である。

同じ悩みを繰り返す人を「意志が弱い」と評価するのではなく、心の中で別々の方向へ進もうとしている自分を一枚の地図へ置く。

地図は次の問いに答えるために作る。

1. 頭では何を望んでいるのか。
2. 現実ではどんな反応を繰り返しているのか。
3. 問題になる前は、どんな自分を自然に発揮できていたのか。
4. 何をきっかけに、どんな考え・行動・価値観を身につけたのか。
5. その生き方を続ける「深層自己」は、何を守ろうとしているのか。
6. 望む自分と深層自己が共有できる目的は何か。
7. 陽の方向と陰で磨いた力を、次の一手へどう使うか。

完成物は診断ではなく、現在の心の構造を選び直せる形にした仮説の地図である。新しい経験が増えたら書き直す。

## 名称の扱い

- 元動画の「インサイトマップ」「インサイドマップ」という名称は、教材内ではすべて **インナーワールドマップ** とする。
- 自動字幕の「深層事故」「新装事故」は、文脈上すべて **深層自己** とする。
- `Higher Compass` は **ハイヤーコンパス**、`Genius Key` は **ジーニアスキー** と読みを併記する。

## 掛け合いの役割

- 清瀬淳：専門語を先に並べず、具体的な日常の一場面から心の構造を説明する。
- 清瀬リンク：初学者が実際に引っかかる疑問を口にする。「意味が分からない」状態を放置せず、誤解しやすい解釈を淳へぶつける。
- 受講者：二人の会話を追って意味を理解した後、選択問題で確認し、自分の例は一文だけ残す。

リンクは内容を要約するだけの復唱役にしない。専門語を別の専門語へ置き換えず、日常の行動として何が違うのかを問い返す。

## 心のモデル

### 悩みの構造

悩みは「こうしたいのに、こうできない」という葛藤として現れる。

この教材では、言語化できる望みだけでなく、感情・身体反応・いつもの選択にも別の自分の意図が現れていると捉える。「複数の自分」は病名や人格診断ではなく、葛藤を観察しやすくするためのモデルである。

### 陽の自分

苦しい体験より前、または問題とは別の場面で、自然に夢中になれた、表現できた、自分から動けた時の自分。将来の方角を見つける材料になる。

### 深層自己

境目となる体験の後に作った考え方・行動・価値観を使い、現在の問題場面で何かを守ろうとする自己モデル。本人の全部ではなく、消す敵でもない。

### 統合

望む自分と深層自己の手段は反対でも、その奥に共通する目的があるかを探す。共通目的が見つかったら、古い問題を繰り返さずに同じ目的へ進める新しい手段を作る。

### ハイヤーコンパスとジーニアスキー

- ハイヤーコンパス：陽の体験から見つける、自分を自然に発揮しやすい未来の方角。
- ジーニアスキー：陰の生き方そのものではなく、その中で実際に磨いてきた観察力・発想・粘りなどの能力。

過去の苦痛を才能と美化しない。古い使い方から能力を分け、望む方向へ使い直す。

## 実演セッションから教材へ移す対話技術

### [特典セッション1](https://youtu.be/eSGEJxc3wBo)

- コーチが人物名を与えず、「どんな自分と言えそうか」と本人に言葉を返す。
- 相談者が出した「悪と戦う戦士」などの比喩を残し、一般的な心理用語へ勝手に置換しない。
- 現在の問題から直接、陰の記憶へ飛ばない。自己発揮できた自分を先に確認する。
- 長い回答を復唱せず、次の問いに必要な核だけを一度まとめて確認する。

### [特典セッション2](https://youtu.be/EtXDKPnUpbU)

- 仕事とパートナーシップの別々の問題から、「期待へ応えようとして無理をする」という共通行動を仮説として置き、本人へ確認する。
- コーチの仮説を事実にしない。「この認識で合っていますか」と主導権を返す。
- 理想を「自分らしく」だけで終わらせず、誰へ何を届けたいかまで具体的にする。
- 本人がすでに知っている内容を答えとして奪わず、次の発見へつなぐ。

## 会話の品質基準

- 本人の答えを語尾だけ変えて復唱しない。
- 答えの中から次の地図に必要な核を一つ受け取り、橋渡しする。
- 原因、記憶、診断、深層自己をAIが勝手に作らない。
- 「なぜ？」だけで追い込まず、どの時・どの場面・誰の行動を聞いているか明示する。
- 抽象語を書いた直後に、必ず日常でカメラに映る行動へ戻す。
- 強い体験を思い出せない、または話したくない人は空白のまま進める。
- 外的要因を否定しない。地図にするのは本人が選び直せる部分である。
- 医療・心理の診断や治療を代替せず、深刻な症状や危険は適切な専門家へつなぐ。

## 実装

- コース入口：`/learn/inner-world-map`
- 6章を順番に解放し、各問いは文字と音声の両方で回答できる。
- 回答は端末内へ保存する。
- AIは回答を採点せず、オウム返しを避けて次の地図へつながる核を一文で返す。
- 6章完了後、全回答を一枚の地図として見返し、文章でコピーできる。
- 特典2本は「正解を見る動画」ではなく、問いとまとめ方を観察するセッションルームに置く。
