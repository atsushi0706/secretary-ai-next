# インナーワールドマップ QA記録

## 対象

- 全6講の掛け合い、図解、選択問題、短い入力、章末マップ
- 清瀬淳からのAI応答
- コース一覧、完成マップ、実演セッション室
- スマートフォンとPCの操作

## 5つの視点

### 1. 作家・編集

- 会話は清瀬淳の説明と、清瀬リンクが初学者として抱く疑問の往復にした。
- 各問いの直前に、何を確かめる問いかを明記した。
- 「その時」「それ」だけで始めず、直前の画面で示した場面を指す場合だけ使用した。
- 1章から6章を、葛藤→反復→陽→陰→統合→未来の順で一本につないだ。
- AIには復唱、原因の創作、幼少期や深層自己の断定をさせない。
- AI返答の直後には追加入力欄がないため、答えられない質問で終わらせない。

### 2. 学習設計・初学者

- 専門語は、使う画面で初めて定義する。
- 顕在意識→潜在意識→文化的催眠→自動反応→深層自己→統合の順にし、前の言葉を理解しないと次へ進めない飛躍をなくした。
- 自分の過去や原因を聞く前に、日常の具体例と選択式の理解確認を置いた。
- 一画面では一つの判断だけを求める。
- 性格の評価ではなく、カメラで見える行動へ言い換える補助を置いた。
- 過去を思い出せない場合と、強い記憶を扱いたくない場合のスキップを用意した。
- 「信念が現実に反映される」を、注意・解釈・選択の積み重ねとして説明した。

### 3. コーチングと安全性

- 外的要因を否定せず、自分で選び直せる範囲だけを地図にする。
- 深層自己を人格全体、病名、倒す敵として扱わない。
- AIは本人が話していない原因や記憶を作らない。
- 強い症状や危険がある回答では、分析を続けず専門家への相談を促す。

### 4. ゲーム・体験

- 6つの領域を一つずつ解放するワールドマップにした。
- 掛け合いは一画面一台詞で、タイプライター表示にした。
- 選択問題は正解・不正解だけで終わらず、なぜ違うかをその場で返す。
- 自由記述はセッションの中心ではなく、学んだ概念を一文だけ自分へ当てはめる確認にした。
- 章末で入力が地図へ変わり、最終章で全体マップが完成する。
- 完了後も章の再訪、全体マップの閲覧、最初からの再作成ができる。
- 実演セッションは結論を見る動画ではなく、問いによる地図化を観察する別室にした。

### 5. デザイン・操作

- コース一覧ではエリクソン編と明確に別シリーズとして表示する。
- 入力欄に既存の録音ボタンを移植した。
- 戻る、次へ、章から出る、再開、リセットを明示した。
- 回答済みの入力画面へ戻った時は再送を求めず、そのまま進むか書き直すかを選べる。
- スマートフォンではカードと回答を一列にし、下部操作を固定した。
- 長い回答は `overflow-wrap` でカード内に収める。

## 機械検査

- `npx tsc --noEmit`：合格
- 教材関連5ファイルへのESLint：合格
- `npm run build`：合格
- リポジトリ全体のESLint：既存コードに793件のエラーがあり不合格。今回追加した教材ファイルには新規エラーなし。

## 学習主導版の通し確認（2026-08-30）

開発用の未ログイン画面 `/dev/inner-world-map` で、390×844のスマートフォン表示を使い、次を確認した。

- コース入口で「何を学ぶか」が、顕在意識・潜在意識・文化的催眠・深層自己として分かる：合格
- 清瀬淳と清瀬リンクの台詞が一画面ずつタイプライター表示される：合格
- 初学者役のリンクが、別人格・常識の全否定・深層自己を消す、といった誤解を質問する：合格
- 6講45画面を先頭から連続操作し、停止せず学習ノートへ到達する：合格
- 全6問で選択、正誤表示、理由の解説、次画面への遷移が動く：合格
- 自分の例を書かずに進んでも、講義の意味が欠けず最後まで進める：合格
- 入力、戻る、講義マップへの退出、進捗保存、復習が動く：合格
- 390px幅でホーム、掛け合い、図解、選択、入力、完成ノートに横はみ出しがない：合格
- 通し操作中のブラウザコンソールにエラー・警告がない：合格

公開URL `https://singaworld.rinq-systeme.jp/learn/inner-world-map` で管理者セッションを使い、次を確認した。

- 一覧の別シリーズカードから教材へ入れる：合格

- 第1章の二つの回答が章末地図へ反映される：合格
- 第1章完了で第2章が解放され、進捗が1/6になる：合格
- 完成マップが開き、未入力項目と入力済み項目を区別できる：合格
- 実演セッション室に指定されたYouTube動画が2本表示される：合格
- 教材を操作した範囲でブラウザのエラー・警告がない：合格
