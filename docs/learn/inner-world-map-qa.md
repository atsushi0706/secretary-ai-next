# インナーワールドマップ QA記録

## 対象

- 全6章の教材本文、入力、章末マップ
- 清瀬淳からのAI応答
- コース一覧、完成マップ、実演セッション室
- スマートフォンとPCの操作

## 5つの視点

### 1. 作家・編集

- 各問いの直前に、何を確かめる問いかを明記した。
- 「その時」「それ」だけで始めず、直前の画面で示した場面を指す場合だけ使用した。
- 1章から6章を、葛藤→反復→陽→陰→統合→未来の順で一本につないだ。
- AIには復唱、原因の創作、幼少期や深層自己の断定をさせない。
- AI返答の直後には追加入力欄がないため、答えられない質問で終わらせない。

### 2. 学習設計・初学者

- 専門語は、使う画面で初めて定義する。
- 一画面では一つの判断だけを求める。
- 性格の評価ではなく、カメラで見える行動へ言い換える補助を置いた。
- 過去を思い出せない場合と、強い記憶を扱いたくない場合のスキップを用意した。
- 「信念が現実に反映される」を、注意・解釈・選択の積み重ねとして説明した。

### 3. コーチングと安全性

- 外的要因を否定せず、自分で選び直せる範囲だけを地図にする。
- 深層自己を人格全体、病名、倒す敵として扱わない。
- AIは本人が話していない原因や記憶を作らない。
- 強い症状や危険がある回答では、分析を続けず専門家への相談を促す。

### 4. ゲーム・体験

- 6つの領域を一つずつ解放するワールドマップにした。
- 自由記述のたびに清瀬淳が一つの核だけを受け取り、次へつなぐ。
- 章末で入力が地図へ変わり、最終章で全体マップが完成する。
- 完了後も章の再訪、全体マップの閲覧、最初からの再作成ができる。
- 実演セッションは結論を見る動画ではなく、問いによる地図化を観察する別室にした。

### 5. デザイン・操作

- コース一覧ではエリクソン編と明確に別シリーズとして表示する。
- 入力欄に既存の録音ボタンを移植した。
- 戻る、次へ、章から出る、再開、リセットを明示した。
- 回答済みの入力画面へ戻った時は再送を求めず、そのまま進むか書き直すかを選べる。
- スマートフォンではカードと回答を一列にし、下部操作を固定した。
- 長い回答は `overflow-wrap` でカード内に収める。

## 機械検査

- `npx tsc --noEmit`：合格
- 追加4ファイルへのESLint：合格
- `npm run build`：合格
- リポジトリ全体のESLint：既存コードに793件のエラーがあり不合格。今回追加した教材ファイルには新規エラーなし。

## 公開後の実機確認

公開URLで、管理者セッションを使い、次を確認して記録する。

- 一覧から教材へ入れる
- スマートフォン幅で横にはみ出さない
- 第1章で入力、AI応答、次への遷移が動く
- 戻ると回答が残る
- 第1章完了で第2章が解放される
- 完成マップと実演セッション室が開く
- ブラウザのコンソールに教材由来のエラーがない
