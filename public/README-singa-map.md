# 地図の画像を置く場所

シンガワールドの背景に、宝の地図の画像を使います。

## やること

地図の画像を、このフォルダに **`singa-map.jpg`** という名前で保存してください。

```
secretary-ai-next/public/singa-map.jpg
```

- ファイル名は必ず `singa-map.jpg`（拡張子も小文字）
- jpg / png どちらでも動きますが、名前は `.jpg` のままにしてください
- 横長（4:3 くらい）が一番きれいに収まります

置いたら、いつも通り送信（コミット）すれば背景に反映されます。

## 画像が無いときはどうなる？

背景が暗いままになります。エラーにはなりません。
地図の場所（光っている点）や会話は、画像が無くても普通に使えます。

## 場所の位置について

地図の上の光る点の位置は `src/lib/places.ts` の `x` / `y` で決めています。
画像を差し替えて位置がずれた場合は、その数字（％）を直せば合わせられます。
